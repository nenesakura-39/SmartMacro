SmartMacro records your mouse and keyboard, lets you edit the steps, and plays them back.
It can wait for text, images or colors on screen, use If / Repeat blocks, and run
feedback loops. SmartMacro has no online features: your macros, settings and logs
stay on your PC (see EULA.txt, section 5, for exactly what is stored).

SmartMacro is intended to remain free to download and use. Supporting KuroLogic through
Ko-fi is completely voluntary.

REQUIREMENTS
- Windows 10 version 2004 (May 2020 Update) or newer, or Windows 11, 64-bit.
- Nothing else to install (the .NET runtime is included).
- For "Find text": a Windows OCR language (most PCs already have one).

INSTALL
1. Download SmartMacro only from the official KuroLogic Discord server
   (https://discord.gg/CKBk5KnGmk) or the Google Drive link posted there.
2. Unzip the file to a folder, for example Documents\SmartMacro.
3. Double-click SmartMacro.exe.
4. Windows SmartScreen may say "Windows protected your PC" because the app isn't
   code-signed. Click "More info" -> "Run anyway" only if you downloaded it from the
   official KuroLogic Discord server or its Google Drive link.
Your macros and settings are stored in %LOCALAPPDATA%\SmartMacro.

SAFETY
- Press Esc to stop a running macro immediately.

REPORT A BUG OR SEND FEEDBACK
- Post it in the KuroLogic Discord server: https://discord.gg/CKBk5KnGmk

  includes your Windows version, screen size, the data folder path (which contains
  your Windows user name) and recent log lines, so check it before posting.
