# KuroLogic brand kit

Source files (vector, edit these):
- `kurologic-mark.svg` – the mark: obsidian hexagon ("kuro" = black) holding a circuit-node "K" (logic).
- `kurologic-logo.svg` – horizontal lockup for dark backgrounds (white "Kuro", gradient "Logic", SOFTWARE STUDIO · クロロジック).
- `kurologic-logo-light.svg` – the same lockup for light backgrounds (dark "Kuro").
- `banner.html` – 1920×1080 showcase (Discord / YouTube / social posts).

Rendered files in `Assets/`:
- `KuroLogic-Logo.png` (dark UI, transparent, 1768×498) – shown in SmartMacro → Settings → About (WPF Resource).
- `KuroLogic-Logo-Light.png` (light backgrounds, transparent, 1768×498).
- `KuroLogic-Mark-1024.png` (mark only, transparent) – avatars, favicons, Discord server icon.
- `KuroLogic-Banner-1920x1080.png` – showcase image.

Palette: obsidian #05070D / #090D18 / #141A2E · cyan #22D3EE / #38BDF8 · indigo #818CF8 · violet #A855F7 / #C084FC ·
titanium #F8FAFC → #CBD5E1 · text muted #94A3B8. Fonts: Inter Display ExtraBold + Light (wordmark), Inter SemiBold
(tagline), Noto Sans CJK JP / Yu Gothic UI (katakana). Inter is SIL Open Font License (free for logos).

Re-rendering: open an SVG in Chrome / Edge and screenshot it at 2× (or import it into Figma / Inkscape and export PNG).
The PNGs were made with headless Chromium at device scale 2 and trimmed. Keep the white "Kuro" variant on dark
backgrounds only; use the light variant on white.
