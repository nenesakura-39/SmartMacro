SmartMacro feedback loop test page

Works offline. Keep the browser zoom at 100 % and don't move or resize the window after you picked the bar area in SmartMacro.

Input: released Presses: 0

Mode 1: the red marker moves by itself. The white zone is fixed at 40–60 %.

SmartMacro settings for mode 1: bar area = the dark bar, marker color #FF0000, zone "a fixed part of the bar" 40–60 %, left of zone = Hold down, inside = Keep as it is, right of zone = Release.

For mode 2: zone "found by its color" #FFFFFF, left of zone = Release, inside = Keep as it is, right of zone = Hold down; done when color #00C800 is in the status square, failed when color #0000C8 is there. Put the mouse over the bar first (a Move mouse step) so the presses land on this page.
